They are condensed, project-neutral language notes maintained by ShiYuPro,
including adaptations of the [Mozilla localization style guides](https://github.com/mozilla-l10n/styleguides)
by Mozilla and their contributors (CC BY 4.0). Changes include condensation into
Chinese guidance, separation of UI labels from explanatory prose, project-specific
terminology exceptions, and illustrative examples. Each profile retains specific
source links. This attribution does not imply endorsement or native-speaker review.

Other linked projects were consulted as references for language conventions and
technical facts; their source files are not bundled. Links do not grant permission
to copy material from those projects. In particular, no license was identified in
the repository metadata for w00ing/skills during the public-release review; treat
it as a reference only, not a reusable source of code or text. The Arabic registry
entry's original provenance was not established, so no implementation is imported.

Profiles inherited a dated review note from their original development. That note
is not a claim that every linked source was newly checked during this release.
Runtime plural behavior must still be checked against the target platform's ICU/CLDR.
