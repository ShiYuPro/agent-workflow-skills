# Русский — русскоязычный интерфейс

适用：本项目ru-RU商店基线；俄语用户可在其他地区，不能据语言假设所在地或付款方式。

这是语言审校参考，不是已批准的产品译文。用户与项目已确认用法优先；示例用于说明方法，不用于自动替换。

## 语言与场景

- 确认ты／вы约定；普通产品面向多人的вы通常小写，个人正式信函另议；按钮常用Сохранить等不定式。
- 数量后的名词屈折按完整句处理：1 запись、2 записи、5 записей；介词、格与形容词都可能改变。
- 动态姓名、菜名或品牌不应随意猜格、性别；必要时改成清楚的标签和值，保留真正责任主体。
- 使用成熟软件词汇并按上下文拆分含义，例如人的имя与事物的название；ё不能全局删去，尤其姓名或含义会受影响时。

## 格式与语法验收

测试0、1、2、5、11、21、22、25及小数。CLDR cardinal one/few/many/other，小数常走other；数字、日期、单位用formatter。

## 场景例

- 场景：记录数量（示意完整数量短语）
- 待改表达：`1 записей / 2 записей / 5 записи`
- 参考表达：`1 запись / 2 записи / 5 записей`
- 判断：检查数量变化；放入句子后还须检查格，不能把本例当通用片段。
