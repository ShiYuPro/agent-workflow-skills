# Locale evaluation

[locale-evaluation.json](locale-evaluation.json)包含12语言×3场景，共36项：特有表达、健康语义不变量、数量/日期/窄屏。语言参考是代理编写的示例，不是唯一答案或母语认证。它们用于未来改动比较，不能因为文件存在就声称语言质量已通过。

当修改语言档案时，选受影响语言的场景完成实际输出，再评估含义、地区、语域、术语、格式分别是否有问题。较大改动覆盖全部语言；运行时生成内容沿用runtime-ai-output-evaluation.md的重复采样与分语言统计。没有UI时只验语言并明确布局/RTL待验。

- 确定错误：否定丢失、参数错位、格式语法损坏、错地区资源、状态升级。
- 可选调整：两个正确且合语境的同义表达、项目未规定的敬称/标点。
- 待确认：源意不明、用量权益无证据、需母语者判断的边缘表达。

禁止按字符串完全相等验自然程度；禁止自评分冒充母语者审核；不把测试例的产品事实移入真实产品。

脚本回归另由scripts/test_check_placeholders.py验证参数和语法行为；它不评价语言自然度。
